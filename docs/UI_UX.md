# KARATARKHIS CRM — UI/UX Canonical Rules

## Status
A canonical web frontend is currently MISSING. Existing Google Sheet workspaces and Telegram are migration-era interfaces, not the final frontend.

## Global
Persian-first, RTL-native, Vazirmatn, responsive, accessible. Technical identifiers (HS, Case ID, B/L, invoice numbers) must use LTR isolation.

## Admin/Employee navigation target
خانه، مرکز فرماندهی، سرنخ‌ها، مشتریان، پرونده‌ها، وظایف، اسناد، مالی، ارتباطات، نامه‌نگاری، هوش مصنوعی، گزارش‌ها، کارکنان و دسترسی، تنظیمات، Audit/System.

## Customer Portal
خانه، پرونده‌های من، اقدامات/وظایف، اسناد، مالی، پیام‌ها، پروفایل.

## Required screens
Customer 360; Case 360; Case Registration Wizard; Lead Pipeline; Task views; Document review; Finance; Communication Hub; AI Center; Smart Correspondence; Reports; Employees/Roles/Permissions.

Every screen must define loading, empty, error, permission-denied and mobile states. No dead buttons or fake actions.
