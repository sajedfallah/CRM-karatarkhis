## Critical fixes

- Repairs legacy Jalali dates accidentally stored as Gregorian year 13xx/14xx values before any immediate processors run.
- Normalizes Lead date columns to actual Date values, including `Assigned At`, so 48h/72h Lead SLA reminders no longer silently skip string dates.
- Updates Lead ID routing to support current IDs such as `YAZD-B01-001` in addition to legacy `YZ-123` IDs.
- Sets `LEAD_BATCH_SIZE` to 10.
- Rebuilds Ardavan's desk as a dynamic view of up to 10 open tasks plus 10 leads from the latest active batch instead of hard-coded physical rows.
- Rebuilds Company Profile with reserved spill blocks to eliminate `#REF!` collisions.
- Rebuilds Alert Center with reserved spill blocks and correct manager-escalation counting.
- Rebuilds Import/Export report with reserved spill blocks.
- Repairs dashboard active-batch formulas to use the latest active batch.
- Removes inherited checkbox validation from task metadata columns P:W; only O remains a checkbox.
- Adds a safe scheduler for morning/noon/evening, weekly, monthly and hourly Lead SLA processing.
- Adds `validateCRMV4101()` / `diagnoseV4101()` for post-install verification.
- Adds/repairs the System Guide sheet.

## Deployment

1. Back up the production Sheet.
2. Replace the Apps Script project code with the complete Drive V4.10.1 file.
3. Preserve Script Properties (`BOT_TOKEN`, `GROUP_CHAT_ID`, `SPREADSHEET_ID`, and other environment values).
4. Save the project.
5. Run `setupV4101()` once and approve required permissions.
6. Run `diagnoseV4101()`.
7. Confirm the validation JSON has no missing sheets, no formula errors, no legacy date cells, no duplicate triggers, and `leadBatchSize: 10`.

Do not run the old `installTriggers()` as an additional deployment step; V4.10.1 installs its scheduler itself.
