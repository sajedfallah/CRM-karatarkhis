# KARATARKHIS CRM V4.10.4 — Customer Type Lock

## Business rule
`نوع مشتری` is now a fixed two-value domain:
- حقوقی
- حقیقی

## Fixes
- Removes accidental `بازرسی` and any other extra customer-type values from `فهرست‌ها!L2:L100`.
- Keeps `مشتری جدید!B3` validation strictly on `فهرست‌ها!L2:L3`.
- Keeps `مشتریان!B2:B1000` validation strictly on `فهرست‌ها!L2:L3`.
- Removes `نوع مشتری` from the Admin Forms "افزودن آیتم به فهرست‌ها" selector so this fixed vocabulary cannot be extended accidentally.
- Final override of `listColumnForAdminTypeV494_()` rejects manual attempts to add arbitrary customer types.
- Adds `repairCustomerTypeV4104_()`, `diagnoseV4104()`, and `setupV4104()`.

## Install
Replace current Apps Script source with `KARATARKHIS_CRM_BOT_V4.10.4_CUSTOMER_TYPE_LOCK.js`, save, then run `setupV4104()` once. Then run `diagnoseV4104()` and confirm `ok: true`.
