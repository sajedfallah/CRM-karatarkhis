# KARATARKHIS CRM V4.10.5 — Setup Chain Fix

Root cause: `setupV4104()` calls `setupV4103()`, and V4.10.3 tried to run `ensureListValueV4103_('نوع مشتری','بازرسی')`. V4.10.4 intentionally removed `نوع مشتری` from the admin-extensible list map, so the setup chain failed with `نوع فهرست ناشناخته است: نوع مشتری`.

Fix:
- `ensureListValueV4103_()` now honors the locked customer-type rule and skips non-canonical customer type additions.
- Customer type remains exactly `حقوقی` / `حقیقی`.
- `CONFIG.VERSION` is set to `4.10.5`.
- Added `diagnoseV4105()`.
- Added `resumeV4105AfterV4104Failure()` for safe continuation from the observed failed setup without rerunning legacy setup layers or resending setup-time Telegram messages.

Recommended recovery for the current workbook:
1. Replace Apps Script source with V4.10.5.
2. Run `resumeV4105AfterV4104Failure()` once.
3. Run `diagnoseV4105()`.
4. Expected: `customerTypeLocked=true`, `adminCanExtendCustomerType=false`, `masterOnEditCount=1`, `staleEditHandlers=[]`, `leadBatchSize=10`, `ok=true`.
