# V4.11.0 — Customer Manager Inbox + Dynamic Employee Workspaces

## Customer requests
- `تسک‌های مشتریان` extends to 24 columns with requester person, task title, manager-seen flag, and manager-seen timestamp.
- Adds visible sheet `صندوق درخواست مشتریان` for the manager.
- Adds `جدید برای مدیر` and `آخرین درخواست‌های مشتریان` to the management dashboard.
- Routine customer task creation is sent to the responsible employee only; the manager follows routine requests in Google Sheets.
- Existing exceptional SLA escalation remains unchanged.

## Employee workspaces
- `👥 کارمندها` becomes dynamic from the active employee registry.
- Every active employee gets dedicated pages: `میز کار <نام>`, `کارهای <نام>`, `پرونده‌های <نام>`.
- New employee registration automatically provisions the employee pages and refreshes the employee hub.
- Existing specialized `میز کار اردوان` is preserved.

## Current production upgrade
After replacing Apps Script with the V4.11.0 source, run `upgradeV4110()` once, then `diagnoseV4110()`.
Do not run legacy `installTriggers()`.
